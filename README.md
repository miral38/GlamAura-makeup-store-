# GlamAura-makeup-store-
GlamAura is a responsive, multi-page beauty store featuring a Brand Index, Wishlist, Track Order, and Checkout system. Built with HTML, CSS, and JS, it delivers a luxury pink-themed shopping experience . It's the ultimate "Glow Like Never Before" digital destination for makeup enthusiasts.
